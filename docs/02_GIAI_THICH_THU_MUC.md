# Giải thích thư mục

## src/
- Chứa toàn bộ mã nguồn Java.
- Bắt buộc.

## bin/
- Chứa file .class được biên dịch.
- Có thể xóa nếu build lại được.

## datasets/
- Chứa bộ dữ liệu thực nghiệm.
- Không nên xóa.

## Output/
- Chứa kết quả sinh ra khi chạy thuật toán.
- Có thể xóa nếu không cần lưu kết quả.
